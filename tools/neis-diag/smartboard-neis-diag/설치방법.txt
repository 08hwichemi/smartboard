스마트보드 나이스 진단 (읽기만) — 설치와 사용

1. 이 zip을 풀어서 "smartboard-neis-diag" 폴더를 바탕화면 등에 둡니다.
2. 크롬 주소창에 chrome://extensions 입력 → 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" → smartboard-neis-diag 폴더 선택
4. 나이스 로그인 → 교과담임 → 시간표관리 → 전체시간표조회
   → "변경수업조회" 고르고, 보강이 있는 날짜(예: 3학년 10.22~10.23)로 "조회"
5. 크롬 오른쪽 위 퍼즐 조각(확장 프로그램) → "스마트보드 나이스 진단" 누르기
   → "💾 결과를 파일로 저장" → 받아진 나이스진단_….json 파일을 보내 주세요.
6. 확인이 끝나면 chrome://extensions 에서 "삭제"를 눌러 지워도 됩니다.

※ 이 프로그램은 나이스 화면(go.kr)에서 시간표 글자가 어떻게 오는지 보기만 하고,
   아무 데도 보내지 않습니다. 모은 것은 이 컴퓨터의 크롬 안에만 있고, 버튼을 눌러야 파일로 저장됩니다.
