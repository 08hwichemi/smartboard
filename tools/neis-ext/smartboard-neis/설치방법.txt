스마트보드 나이스 변경수업 — 설치와 쓰는 법

[처음 한 번 설치]
1. 이 zip을 풀어 "smartboard-neis" 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다.
   (폴더를 지우거나 옮기면 확장 프로그램이 꺼집니다)
2. 크롬 주소창에 chrome://extensions → 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" → smartboard-neis 폴더 선택
4. 전에 설치한 "스마트보드 나이스 진단"은 "삭제"를 눌러 지워도 됩니다.
5. 나이스 탭은 한 번 닫고 새로 열어 로그인합니다(새로 설치한 프로그램이 붙게).

[매일 쓰는 법]
1. 같은 크롬에 스마트보드(https://08hwichemi.github.io/smartboard/)를 열어 둡니다.
2. 나이스 → 교과담임 → 시간표관리 → 전체시간표조회 → "변경수업조회"
   → 일자를 넉넉히(예: 지난주 월요일 ~ 3주 뒤) 잡고 학년마다 "조회" (1학년 → 2학년 → 3학년)
3. 스마트보드 탭에 "📥 나이스 변경수업 가져오기" 창이 뜹니다. 학년을 더 조회하면 같은 창에 더해져요.
4. 넣을 것(보강·교환)을 확인하고 "○건 넣기". 행사(동아리활동 등)·이미 있는 것은 저절로 빠집니다.

※ 스마트보드 탭이 없을 때 조회했으면, 나중에 스마트보드를 열면 그때 창이 뜹니다(하루 동안 보관).
※ 이 프로그램은 나이스에서 "전체시간표 (변경수업)" 보고서만 읽어 같은 크롬의 스마트보드로 넘깁니다.
   나이스에 스스로 들어가거나 무언가를 누르지 않고, 다른 곳으로 보내지 않습니다.
※ 관리자·수업변경 담당 계정으로 로그인한 스마트보드에서만 창이 뜹니다.
