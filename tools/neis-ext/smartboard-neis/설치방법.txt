스마트보드 나이스 변경수업 (자동) — 설치와 쓰는 법

[처음 한 번 설치]
1. 이 zip을 풀어 "smartboard-neis" 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다.
   (폴더를 지우거나 옮기면 확장 프로그램이 꺼집니다)
2. 크롬 주소창에 chrome://extensions → 오른쪽 위 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" → smartboard-neis 폴더 선택
   (전에 깐 "스마트보드 나이스 진단"은 "삭제"를 눌러 지워도 됩니다)
4. 크롬 오른쪽 위 퍼즐 조각 → "스마트보드 나이스 변경수업" 옆 📌을 눌러 고정해 두면 상태를 보기 편해요.
5. 나이스 탭은 한 번 닫고 새로 열어 로그인합니다(새로 설치한 프로그램이 붙게).

[main에 올리기 전 시험]
· 미리 보기 주소 https://raw.githack.com/08hwichemi/smartboard/claude/serene-albattani-qpka34/index.html 에서도 받아요.
  거기서 로그인해 두고, 나이스 로그인 상태에서 확장 프로그램 아이콘 → "▶ 지금 자동 조회 해 보기".
  (미리 보기여도 실제 시간표 자료에 넣어요 — 잘못 들어가면 알림의 [되돌리기])

[매일 — 할 일 없음]
· 평일 아침, 같은 크롬에 나이스(로그인)와 스마트보드를 열어 두기만 하면 됩니다.
· 8시 40분이 되면 확장 프로그램이 나이스에서
  교과담임 → 시간표관리 → 전체시간표조회 → 변경수업조회 → 일자(이번 주 월~금) → 1·2·3학년 조회를 대신 누르고,
  스마트보드가 나이스에서 바뀐 칸을 그대로 시간표에 넣습니다. 스마트보드 오른쪽 아래에 "바뀐 칸 ○곳을 넣었어요 [되돌리기]" 알림이 떠요.
  (매일 나이스와 견줘 새로 바뀐 칸은 넣고, 원래대로 돌아간 칸은 뺍니다 — 스마트보드 시간표가 늘 나이스와 같게)
· 8시 40분에 나이스가 로그아웃돼 있었으면, 나이스에 로그인하는 순간 합니다.
· 그날 한 번 한 뒤 3시간 넘게 지나 나이스에 다시 로그인하면 한 번 더 합니다(수업계가 낮에 나이스에서 바꾼 것까지).
  받으려면 PC가 켜져 있고(모니터는 꺼져도 됨, 절전은 안 됨) 같은 크롬에 스마트보드 탭이 열려 있어야 해요.
· 정기고사와 행사(동아리활동 등) 칸은 넣지 않아요.

[확장 프로그램 아이콘을 누르면]
· 오늘 자동 조회가 끝났는지 / 실패했으면 이유
· 자동 조회 켜기·끄기, 시각 바꾸기
· "▶ 지금 자동 조회 해 보기" — 나이스 로그인 상태에서 바로 해 봄
· "📋 마지막 자동 조회 기록 저장" — 잘 안 될 때 이 파일을 보내 주세요(어느 단추를 못 찾았는지 들어 있어요)

※ 나이스에서 직접 변경수업조회를 눌러도 그 학년·기간을 똑같이 맞춰 넣어요.
※ 이 프로그램은 나이스의 "전체시간표 (변경수업)" 보고서만 읽어 같은 크롬의 스마트보드로 넘기고, 다른 곳으로 보내지 않습니다.
※ 관리자·"나이스 시간표 받기" 계정(관리자 설정 → 계정 관리에서 체크)으로 로그인한 스마트보드에서만 넣습니다.
