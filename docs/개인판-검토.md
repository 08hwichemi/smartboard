# 🧳 개인판(서버 없는 스마트보드) 검토 — 2026-10-18

사용자 요청: "친한 선생님들이 깃허브 링크로 바로 쓰게. 서버 연결 없이 로컬 저장·백업 파일로.
쓰게 할 기능 = 명렬표·단축키·생기부·수행평가·양식·좌석배치표·월간일정표·결석계·조퇴증.
홈은 없앨지, 내 시간표 직접 입력 + 캘린더·½캘린더만 둘지 고민. 학교 이름으로 학사일정·급식을 끌어오면 좋겠다.
빼야 할 것·고쳐야 할 것 검토."

## 결론 먼저

**가능하다. 큰 재작성 없이 된다.** 이유는 지금 구조가 이미 "개인 자료는 브라우저(localStorage)가 원본이고 서버는 동기화만" 이기 때문이다.
- 요청한 9개 기능 중 **8개는 자료가 이미 각자 브라우저에 저장**된다(수행평가·생기부 편집기·좌석배치표·월간일정표·결석계·조퇴증·양식·단축키). 서버는 `user_data_items`에 복사본을 올릴 뿐이라 **동기화만 끄면 그대로 돈다.**
- **백업·복원도 이미 있다.** 홈 💾 백업 = 개인 자료 전체를 JSON 파일로 내려받기/복원, 15일마다 다운로드 폴더에 자동 백업. 개인판에선 이게 유일한 보관 수단이 되므로 눈에 띄게 올리면 된다.
- 유일하게 서버에 있는 건 **명렬표(`students` 표)** 다. 읽는 곳이 8곳(아래 표)이라 이걸 "브라우저에 저장 + 엑셀로 가져오기" 로 바꾸는 게 핵심 작업이다.
- 급식·학사일정·날씨는 지금도 공개 API(나이스·open-meteo)를 **브라우저가 직접** 부른다(서버 안 거침). 학교 코드만 바꾸면 다른 학교 것이 나온다.

추천 방향: **홈을 없애지 말고 "개인 홈"으로 줄인다**(절충안, 아래 §3). 저장소는 **같은 저장소 안에 `lite/` 폴더로 따로 빌드**(§5).

## 2. 요청한 9개 기능 하나하나

|---|---|---|---|
| 📋 명렬표 (`loadStudentRoster`) | **서버 `students`** | 읽기 8곳 + 관리자 엑셀 업로드(`admin_replace_students_for_grade`) | **수정(핵심)**. 명렬표 패널에 "📥 엑셀로 가져오기"(지금 관리자 업로드 파서 재사용) + 전화번호 수정은 로컬. 저장은 localStorage `roster-<학년>-<반>`(한 반 수백 바이트, 백업 JSON에 자동 포함) |

| 📄 양식 (명렬표 수합·학습지·수행평가·안내문·시정표·이름표·시험 이름표) | localStorage + 시험 이름표는 IndexedDB(`smartboard-local`) + 자체 백업 파일 | 명렬표 수합(`fmLoadRoster`)·사물함 이름표(`ntLkLoadRoster`)·시험 이름표(`etImportRoster`)가 명단 읽음 | **그대로**, 명단 읽기만 로컬로. **🏫 학교 가정통신문 양식은 부광고 머리 그림(`forms/가정통신문-머리.jpg`)이라 빼거나 "머리 그림 올리기"로** |
| 🪑 좌석배치표 | localStorage(디자인·결과 파일 저장/불러오기도 있음) | 반 명단만(`scLoadRosterFromDB`) | **그대로**, 명단 읽기만 로컬로 |
| 🗓️ 월간일정표 | localStorage `ms-*` | 나이스 학사일정(공개 API) | **그대로**. 학교 이름 기본값 "부광고등학교"(`#ms-cfg-school`, `#ms-print-school`) → 설정의 학교 이름 |
| 📋 결석계 | localStorage `ab-r-*`(건강 사유라 애초에 개인 자료) + `absence/forms.json`(정적) | 반 명단만(`abLoadRoster`) | **그대로**, 명단 읽기만 로컬로 |
| 🎫 조퇴증 | localStorage | 없음(학교·학급 칸은 이미 직접 입력) | **그대로**. 학교 칸 기본값만 설정에서 |

→ 명단을 읽는 8곳(`sb.from('students')`)을 **함수 하나 `rosterGet(grade, classNo)`** 로 모으고, 그 안에서 localStorage를 읽게 바꾸면 끝. 각 기능의 나머지 코드는 손대지 않는다.

**시간표 만들기(🗓️ 레일 `rail-persontt`, 학생·교사 카드형 시간표 출력)** 는 요청 목록엔 없지만 개인 자료(`pt-design`)만 쓰고 서버 의존이 없다 → 넣어도 된다(사용자 결정).

## 3. 홈을 어떻게 할지 — 추천: 절충안("개인 홈")

| 홈 구성 요소 | 지금 | 개인판 |
|---|---|---|
| 시계·날짜·D-day | 로컬 | **유지** |
| ⭐ 내 시간표 | 서버 `timetable`(관리자 엑셀) | **직접 입력으로 바꾸기** — 설정 안 "교사 시간표 수정 표"(저장 버튼 있는 격자, `ttscroll-test`) UI를 그대로 떼어 와 localStorage에 저장. 안 입력하면 칸을 숨김 |
| 🔍 찾아보기 시간표(다른 선생님) | 서버 | **삭제** |
| 📢 공지(👍❤️) · 감독표 · 🔁 수업 변경 | 서버(학교 공용) | **삭제** |
| 🍱 급식 | 나이스 직접 호출 | **유지**(학교 코드만 설정에서) |
| 🌤 날씨 | open-meteo, 좌표 고정(인천) | **유지**, 좌표는 §4 |
| 📰 뉴스 · 구글 검색창 | 뉴스 = 서버 함수 / 검색 = 로컬 | 뉴스 **삭제**, 검색창 **유지** |
| 📅 캘린더 · ½캘린더(메모 `cal-memo-*`) | 로컬 + 나이스 학사일정 | **유지** |
| ✅ 할 일(업무·학생) · 즐겨찾기 | 로컬 | **유지** |
| 🧑‍💼 실무사 홈 · 학생 시간표 카드 | 서버·역할 | **삭제** |

왜 홈을 아예 없애는 쪽(안 A)보다 나은가: 캘린더·½캘린더·할 일·급식·날씨는 이미 로컬/공개 API라 **지울 일만 있고 만들 일이 없다.** 오히려 홈을 없애면 "열면 바로 보이는 첫 화면"을 새로 만들어야 한다. 시간표는 "직접 입력하면 보이고, 안 하면 접힘"으로 두면 학교마다 양식이 달라도 상관없다(격자는 요일×교시만 있으면 됨, 교시 수·일과 시간은 설정값).

## 4. 학교 이름 → 학사일정·급식·날씨

- 나이스 **`schoolInfo`** 서비스(`SCHUL_NM=학교이름` 검색)로 교육청 코드(`ATPT_OFCDC_SC_CODE`)·학교 코드(`SD_SCHUL_CODE`)가 나온다. 같은 이름이 여러 개면(예: "중앙고") 지역과 함께 골라 저장. 지금 코드에는 이 호출이 없고(`EDU_CODE='E10'`, `SCH_CODE='7310046'` 고정), 급식·학사일정 호출 8곳은 이 두 상수만 쓰므로 **상수를 설정값으로 바꾸면 바로 다른 학교가 나온다.**
- 처음 열 때 "학교 이름을 입력하세요" 설정 화면(이름·학교·일과 시간)을 한 번 띄운다.
- **날씨 좌표**: 학교 주소를 지도 좌표로 바꾸는 외부 서비스 없이 — ① 교육청 코드(17개 시·도) → 시·도 대표 좌표 표(코드 안 고정) 로 충분히 맞고, ② 원하면 브라우저 위치 권한으로 더 정확히. ①을 기본으로 추천.
- **나이스 인증키 한 개를 모두가 공유**한다(지금도 코드에 공개돼 있음, 키는 무료·호출 한도는 하루 단위). 급식·학사일정은 하루에 한 번만 받아 localStorage에 캐시하면 10~20명이 써도 문제 없다. 걱정되면 설정에 "내 나이스 키" 칸(비우면 공용 키).

## 5. 어떻게 만들지 — 저장소·배포

**추천: 같은 저장소, `lite/` 폴더에 빌드.**
- `index.html`에 상수 `APP_MODE = 'school'`을 두고, 서버가 필요한 곳은 `if (APP_MODE === 'personal')` 로 갈라 둔다(로그인 건너뛰기, 동기화 끄기, 레일 버튼 숨김, 홈 위젯 숨김, 명단 로컬 읽기).
- `tools/개인판만들기.py`(판올리기.py와 같은 식)가 `index.html`을 복사해 상수만 `'personal'`로 바꿔 `lite/index.html`로 쓰고, `sgb/`·`absence/`·`forms/`는 상대 경로를 `../`로 맞춘다(또는 그대로 쓰게 경로 상수 하나).
- 주소: **https://08hwichemi.github.io/smartboard/lite/** — 판올리기 때 함께 만들어 올리면 학교판과 개인판이 늘 같은 코드.
- 대안(별도 저장소 `smartboard-lite`): 주소는 깔끔하지만 고칠 때마다 두 곳에 올려야 해서 금방 어긋난다. 코드가 한 파일(1.9MB)이라 분기 상수 방식이 유지가 훨씬 쉽다.

**개인판에서 빼는 코드**는 지우지 않고 숨긴다(상수로 갈라 둠) — 한 파일을 유지하기 위해. 다운로드 크기(1.9MB)는 GitHub Pages가 압축해서 보내므로 괜찮다.

**설명서**: 홈 설명서 투어(`tour-test`)와 `guide.html`·`guide/부광고_스마트보드_사용안내.pdf`는 부광고 로그인 기준이라 개인판엔 **첫 설정 화면 + 백업 안내문 한 장**만 따로 쓴다.

## 6. 꼭 알려야 할 것(개인정보·자료 보관)

- 명렬표·결석계·수행평가·생기부가 **그 컴퓨터의 브라우저에만** 남는다. 브라우저 자료 삭제·다른 컴퓨터·다른 브라우저(Chrome↔Edge)면 안 보인다 → 💾 백업 파일을 USB 등에 두라고 첫 화면과 각 화면 머리에 쓴다. (15일 자동 백업은 이미 있음.)
- 백업 JSON은 **암호가 없다**(학생 이름·전화·결석 사유 포함). 공용 PC·교무실 공용 계정에선 쓰지 말라고 안내. 원하면 다음 단계로 "비밀번호로 잠근 백업"(브라우저 WebCrypto) 추가 가능.
- 학교판과 달리 기기 간 동기화가 없다 — "PC와 휴대폰이 따로"라는 점을 미리 말해야 한다.

## 7. 작업 순서·크기 (코드는 아직 안 고침 — 결정 뒤 시작)

1. `APP_MODE` 상수·빌드 스크립트·`lite/` 배포 뼈대 — 작음
2. 로그인 건너뛰기 + 가짜 `currentTeacher` + 동기화·한 창 제어 끄기 — 작음(이미 `SB_SLEEP`처럼 분기 자리가 있음)
3. 명단 8곳 → `rosterGet` 로컬 + 명렬표 패널 엑셀 가져오기 — **중간(핵심)**
4. 첫 설정 화면(이름·학교 찾기 `schoolInfo`·일과 시간) + 급식·학사일정·날씨가 설정값을 쓰게 — 중간
5. 홈 줄이기(위젯·레일 숨김, 내 시간표 직접 입력) — 중간
6. 학교 고유 기본값 치우기(월간일정표·조퇴증·시험 이름표의 "부광고등학교", 가정통신문 머리 그림) — 작음
7. 개인판 안내문·백업 강조, 테스트(`tools/tests` 가짜 서버 방식에 "개인판" 시나리오 하나) — 작음

전부 합쳐 채팅 2~3번 분량으로 본다. 3→4→5 순서가 핵심이고 1·2는 3을 시작하기 전에 같이 한다.

## 8. 사용자가 정해 줄 것

1. **홈**: 절충안(§3, 추천) / 홈 없애고 레일만 / 캘린더·½캘린더만
2. **배포**: 같은 저장소 `lite/`(추천) / 별도 저장소
3. **시간표 만들기(카드형 출력)** 넣을지
4. **가정통신문 양식**: 빼기 / 머리 그림 올리기 기능으로 바꾸기
5. 개인판 **이름**(화면 제목·백업 파일 이름에 들어감 — 예: "스마트보드 개인판")
