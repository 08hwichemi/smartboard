구글시트(부광고배경화면.xlsx의 공지사항·야자감독·급식감독·아침감독·전체시간표 탭)로
돌아가던 것을 GitHub Pages + Supabase로 옮겼습니다.

**로그인이 없습니다.** 교무실 공용 화면이라 링크만 있으면 누구나 고칠 수 있고,
Supabase RLS도 `anon`에게 다 열려 있습니다 — 민감한 개인정보는 다루지 않는 화면이라
가능한 설계입니다 (다른 두 앱, 면접ON·수시지원계획서와는 다릅니다. 그 앱들은 로그인이 있고
RLS가 잠겨 있습니다).

## 코드 구조

`index.html` 하나가 전부입니다 (위젯 스타일 + 데이터 불러오기 로직이 한 파일).
서버와 통신하는 부분만 `gas`로 시작하는 함수들(`gasGetDuty`, `gasSetDuty`,
`gasGetNotice`, `gasSetNotice`, `gasGetSchedule`, `gasSetSchedule` 등)에 모여 있고,
나머지(날씨·급식·학사일정·캘린더 메모·즐겨찾기)는 그대로 `localStorage`나
공개 API(open-meteo, 나이스)를 씁니다 — 원래 구글 앱스크립트 버전에서 그대로 가져온
부분이라 건드리지 않았습니다.
